1. Clear & Set Date
Clears DATA!A3:AT22 (columns I and J are left alone) and sets DATA!B2 to the first game date of the next matchweek.
2. Clear Bets
Clears everyone's picks: cells B3:E22 on the Snackbar, Timbo and Pepe sheets.
3. Get Fixture IDs
Fetches the fixtures for whatever matchweek DATA!B2 falls in and writes them into DATA!A3:C. Check the list below looks right before running step 4.
4. Update All Data
Runs updateAllData() to pull scores, stats, odds etc. for the new fixtures. Can take up to a minute or so.
